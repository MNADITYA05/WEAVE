Two directions

One tool, both ways

Whether you are starting from a SPICE card or a drawn schematic, Weave handles the translation — with formal connectivity verification in both directions.

Netlist → Schematic

SPICE text to visual schematic

Parses a flat SPICE netlist, classifies nets as ground, supply rail, or signal, assigns components to layers using the Sugiyama framework via elkjs, routes wires with a bump-and-route pass, and emits a loadable LTspice .asc file.

elkjs layout Sugiyama layers 5,093 symbols

Based on the Weave paper (arXiv 2607.03835). Achieves 88.4% round-trip connectivity match on the Circuits-LTSpice benchmark.

Schematic → Netlist

LTspice .asc back to SPICE text

Reads an LTspice .asc file, resolves each component's pin coordinates using the symbol table, unions wire endpoints with a union-find to determine net membership, and emits a clean flat SPICE netlist. Extracts TEXT directives automatically.

Union-Find SpiceOrder aware Directive passthrough

Original work. Enables the full editing loop: generate a schematic, open it in LTspice, modify it, then extract the updated netlist programmatically.

Algorithm

How Weave works

Three stages, each with a defined correctness guarantee. The verifier runs at every stage — a schematic is only kept if it re-parses to exactly the same connectivity as the input.

01

Parse

The SPICE parser handles all element types (R, C, L, V, I, D, Q, M, J, X, E, G, F, H, B, S, W, T, K), joins continuation lines, and classifies each net as ground, supply rail, or signal. Net classification determines whether a connection becomes a flag or a wire.

R1 in mid 1k
C1 mid 0 100n
→ net "mid" = signal
→ net "0" = gnd
02

Layout

Components are assigned to layers using Sugiyama's algorithm via elkjs. Feedback edges are reversed then restored; special placement patterns handle voltage divider legs, hanging shunts, and supply corners. A safe-mode ladder with 10 degradation levels ensures a result is always produced.

mode 0: full patterns
mode 1: bridge pass
...
mode 9: max spacing
03

Verify

The generated .asc is re-parsed. A union-find merges wire endpoints and flag groups into nets; the resulting partition is compared set-by-set against the source netlist. If any net partition differs, Weave climbs the safe-mode ladder and retries.

compare(netlist, asc)
→ errs.length === 0
→ MATCH ✓

Academic foundation

Original paper

"Weave: Synthesizing Schematics from SPICE Netlists"

The netlist-to-schematic direction implements the approach described in arXiv 2607.03835v1. The paper introduces a verification-first methodology: correctness is defined as connectivity equivalence, checked by re-parsing the output schematic and comparing net partitions against the source netlist.

Graph layout via elkjs (Sugiyama framework, layered algorithm)
Connectivity verification using union-find on wire topology
Safe-mode ladder — 10 levels of layout simplification with automatic retry
